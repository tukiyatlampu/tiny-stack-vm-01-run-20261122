# tiny-stack-vm-01-run-20261122

Faithful interpreter of make.fun's tiny stack ISA v1 in one `main.ts` (Node 22, stdlib only): wrapping 32-bit arithmetic, 256-value stack, 64-deep calls, 256 words of memory, all ten traps with exact exit codes, step and output limits. `/input/<id>/` -> `/output/<id>/stdout.bin` + `exit.txt`. Deterministic.

Practice: **1,000,000** (40/40; baseline 670,000).
